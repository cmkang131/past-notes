선형계획 (1강)

LP 모형 · 꼭짓점 원리 · 그림자 가격 · KKT

핵심 개념
  • 선형계획(LP): 제약 안에서 목표를 최대/최소로 만드는 문제 중, 목표와 제약이 전부 1차식인 것 (제곱이나 변수끼리 곱 없음)
  • 모형의 네 조각: 결정변수 (내가 정하는 것, 예: 만들 개수) / 목적함수 (최대화할 이익, 도달 또는 최소화할 비용) / 제약 (노동·재료·예산·수요 한도, 음수 불가) / 실행 가능 영역 (제약을 다 만족하는 점들)
  • 꼭짓점 원리: 최적해가 있으면 적어도 하나는 실행 가능 영역의 꼭짓점에 있음 → 꼭짓점만 비교하면 됨 (그래프 풀이), Simplex(해 찾기)는 꼭짓점을 따라 이동
  • 라그랑주 승수 = 그림자 가격: 제약을 한 단위 풀어 주면 목표가 얼마나 늘어나는지 = 그 자원의 가치, 시장 가격보다 크면 더 사는 게 이득
  • 여유 있는 제약(다 안 쓴 자원)의 승수는 0 → 이걸 반영한 게 KKT 조건, 무시하고 모든 제약을 등호로 묶으면 음수 승수가 나옴
  • 정수만 되면 정수계획 (더 어려움), 수업은 연속 변수
교수님 설명
  • "오늘이 학기 중 가장 어려운 수업" (수학이 조금 나와서)
  • 결정은 늘 제약 속에서: 자원이 무한하면 그냥 많이 만들면 됨, 현실은 예산·노동·수요에 막힘
  • 순서: 마케팅 문제 이해 → 결정변수 → 목적함수(이익, 비용, 효용) → 제약
  • 제조 쪽은 보통 비용 최소화, 경제학은 이익 최대화로 봄
  • 푸는 법 세 가지 (그래프, 라그랑주, Simplex/해 찾기) 중 수업에서 쓰는 건 해 찾기, 앞의 둘은 원리 이해용
예제 1: Basic, Premium

슬라이드: Basic·Premium 생산 문제를 그래프로 그린 것. 가로축 x₁ = Basic 개수, 세로축 x₂ = Premium 개수. 노동 제약선 2x₁ + 4x₂ = 100은 (0, 25)에서 (50, 0)까지, 재료 제약선 3x₁ + 2x₂ = 90은 (0, 45)에서 (30, 0)까지. 두 선 아래이면서 1사분면인 색칠된 사각형이 실행 가능 영역이고, 최적해는 그 꼭짓점 중 하나.

슬라이드: 실행 가능 영역의 꼭짓점 네 개 (0, 0), (30, 0), (0, 25), (20, 15)에 이익 Z = 30x₁ + 50x₂를 넣어 비교한 표. 0, 900, 1,250, 1,350 중 (20, 15)가 최대 → Basic 20개, Premium 15개.

  • 꼭짓점 확인 → (20, 15), Z = 1,350, 노동·재료 둘 다 다 씀
  • 라그랑주 승수 (노동), (재료)

슬라이드: 라그랑주 승수 = 그림자 가격 (제약을 한 단위 풀 때 최적 이익이 늘어나는 양). 노동 λ₁ = 11.25: 초과근무 시급이 $11.25보다 싸면 사라. 재료 λ₂ = 2.50: 급행 주문에 재료 1단위당 $2.50 넘게 내면 손해. 검산: 100 × 11.25 + 90 × 2.5 = 1,350 = Z (안 맞으면 계산이 틀린 것).

  • 그림자 가격: 노동 1시간 더 있으면 이익이 $11.25 늘어남 → 시급이 그보다 싸면 고용
  • 교수님 질문: "경기가 좋으면 기업이 사람을 더 뽑는 이유?" → 이 값이 시급보다 커서
  • 학생 질문: 몇 시간까지 사도 되나? → λ는 지금 상태에서 한 단위 가치, 늘리고 나면 다시 풀어야 함
예제 2: 카페 (커피, 차)

슬라이드: 카페 문제 그래프 (x₁ = 커피, x₂ = 차). 수요선 x₁ + x₂ = 60이 시간선 4x₁ + 2x₂ = 240보다 거의 전부 아래에 있고 (60, 0) 한 점에서만 만남 → 실행 가능 영역이 꼭짓점 3개짜리 삼각형. 주방 시간이 아니라 수요가 진짜 제약이라는 뜻.

  • 이익 $2, $1.5 / 시간 4, 2분 (총 240) / 하루 수요 합계 60잔 = 시장 크기
  • 시장보다 많이 만들 필요 없어서 수요 제약을 둠

슬라이드: 꼭짓점 세 개에 Z = 2x₁ + 1.5x₂를 넣은 표: (0, 0) = 0, (0, 60) = 90, (60, 0) = 120 → 커피 60잔, 240분을 다 씀. (30, 30)은 수요선 위에 있지만 꼭짓점이 아니라 볼 필요 없음 (봐도 105).

  • 답: 커피만 60잔, $120
  • 교수님 설명: 손님 한 명이 차 → 커피로 바꾸면 이득, 반대면 손해 → 커피만 팜
예제 3: 광고 (TV, SNS)

슬라이드: 광고 문제 그래프 (x₁ = TV 광고, x₂ = SNS 캠페인). 예산선 2000x₁ + 1000x₂ = 20,000이 위쪽 경계, 최소 노출선 x₁ + x₂ = 8이 아래쪽 경계. 두 선은 (12, −4)에서 만나서 영역 안에선 안 만남 → 실행 가능 영역은 (0, 8), (8, 0), (10, 0), (0, 20)을 꼭짓점으로 하는 사각형.

  • 도달 100, 80 / 비용 $2,000, $1,000 (예산 $20,000) / 최소 8회

슬라이드: 네 꼭짓점에 도달 Z = 100x₁ + 80x₂를 넣은 표: (0, 8) = 640, (8, 0) = 800, (10, 0) = 1,000, (0, 20) = 1,600 → TV 0회, SNS 20회.

  • 답: SNS만 20회, 도달 1,600 (달러당 도달이 SNS가 높음)

슬라이드: 그냥 라그랑주가 여기선 왜 안 되나. 왼쪽: 두 제약을 다 등호로 놓고 풀면 λ₂ = −60, 부등식 제약의 승수는 음수가 될 수 없고 교점 (12, −4)도 불가능. 오른쪽 KKT 풀이: 노출 제약은 여유 (20회, 최소 8회) → λ₂ = 0 / 예산 승수 λ₁ = 0.08 = 예산 1달러당 도달 0.08 증가 (20,000 × 0.08 = 1,600 = Z) / TV를 억지로 1회 넣으면 $2,000이라 SNS 2회(도달 160)를 빼야 해서 도달 60 손해 (μ₁ = 60).

  • 노출 제약은 여유 있어서 승수 0 → 그냥 라그랑주로 두 제약을 다 묶으면 음수 승수가 나옴 (KKT)
  • "문제를 해석해서 변수를 정의하는 게 중요, 그다음은 엑셀에 넣고 해 찾기 누르면 됨"
음의 가격 (수업 토론)
  • 전력 과잉 생산 때 전기를 쓰면 돈을 받는 경우 (학생 답), 쓰레기는 내가 돈을 내고 "공급" → 음의 재화
  • 일반 재화는 가격 ≥ 0 제약
