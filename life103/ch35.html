Concept 35.1: In innate immunity, recognition and response rely on traits common to groups of pathogens

Recognition and response
병원체 (Pathogens) : 질병을 일으키는 원인 물질(세균, 바이러스, 진균 등)
면역 시스템의 역할 : 병원체를 피하거나 빠르게 제거하여 감염을 예방·억제하는 방어 체계

Animal immunity

    • 선천면역 (Innate immunity)
      • 감염되자마자 바로 작동하는 1차 방어선
      • Barrier defenses (1차 장벽)
      • 피부, 점막, 분비물
      • Internal defenses (체내 방어)
      • 식세포 → 병원체를 잡아먹음
      • NK 세포 → 감염된 세포를 죽임
      • 항미생물 단백질 → 병원체를 공격
      • 염증 반응 → 손상/감염 부위로 면역 세포를 모음
    • 적응면역 (Adaptive immunity)
      • (척추동물에서만 나타나는 면역)
      • 노출된 후에 발달 (획득면역) → 기억세포를 만들어 이후 감염 시 더 빠르게 대응
      • *특정 병원체에 매우 특이적으로 반응*
      • Humoral response (체액성 면역)
      • B세포 → 항체를 만듦 → 체액 속 병원체를 공격
      • Cell-mediated response (세포성 면역)
      • T세포 중 cytotoxic T cell → 감염된 세포를 직접 죽임

Innate Immunity

    • 1. Barrier defenses (장벽 방어)
      • 병원체가 몸 안으로 들어오는 것을 1차적으로 차단
      • 점액, 체액 분비물, 산성 환경
    • 2. Cellular innate defenses (세포성 선천 면역)
      • Phagocytosis (식세포작용)
      • macrophages(대식세포) - 백혈구
      • ⇒ 병원체를 잡아먹고 분해
      • Natural killer (NK) cells - 백혈구
      • 감염된 세포나 비정상적인 세포에 화학물질을 분비 ⇒ 세포사멸(apoptosis) 유도
    • 3. Antimicrobial peptides / proteins (항미생물 펩타이드·단백질)
      • Interferons(인터페론 단백질)
      • 모든 세포가 코딩하는 DNA를 가지고 있음, 바이러스 생기면 코딩 시작
      • 바이러스 감염 시 세포에서 분비 ⇒ 세포 수용체에 결합
      • ⇒ 대식세포 활성에 도움
      • Complement system (보체 시스템)
      • 40-50종의 단백질 → 면역 반응을 보조
      • 병원체 표면에 붙어 구멍을 뚫어 용해(lysis)
      • 식세포가 병원체를 더 쉽게 인식하게 함(옵소닌화)

Inflammatory response (local or systemic)

    • A type of innate immune response
    • 부상 or 감염 → 우리 몸이 보이는 기본적인 방어 기전
      • local or systemic(전신적)하게 일어남
    • Local inflammatory response
      • 대식세포(macrophages) ⇒ 사이토카인(cytokines)을 분비
      • → 면역세포를 감염 부위로 모집하는 역할
      • 비만세포(mast cells)-백혈구 ⇒ 히스타민(histamine)을 분비
      • → 혈관 확장 ⇒ 투과성을 증가시킴
      • 보체 단백질(complement proteins)
      • → 추가적인 히스타민 분비 + 더 많은 식세포(phagocytes)를 부름
    • Systemic inflammatory response - 발열(Fever)
      • 대식세포가 분비한 물질들
      • → 뇌의 체온 조절 중추에 작용 ⇒ 발열을 유발
      • : 식세포 작용(phagocytosis)을 촉진
      • : 조직 회복 속도를 높임
      • ⇒ 유익한 면역 반응으로 작용

MHC-II class

    • 대식세포, 수지상세포, B세포에 존재. 이들을 APCs라 함.
      • 항원을 밖에서 먹어온 뒤 제시하는 단백질 APC process
      • Helper T세포(CD4+)에게 항원을 보여주는 역할
      • adaptive immunity의 시작 버튼

Concept 35.2: In adaptive immunity, receptors provide pathogen-specific recognition

In adaptive immunity, receptors provide pathogen-specific recognition

    • 적응 면역 adaptive immunity
      • 특정 병원체를 정확히 구별하는 능력 ⇒ 항원 수용체(antigen receptors)
    • 아래 두 종류의 림프구에 의해 수행됨
      • T 세포(T cells) = 성숙 장소 : 흉선(thymus)
      • B 세포(B cells) = 성숙 장소 : 골수(bone marrow)
    • 항원(Antigen)과 인식 과정
      • 항원 수용체(antigen receptor)를 이용해 항원을 인식
      • B 세포 → BCR (B cell receptor)
      • T 세포 → TCR (T cell receptor)
      • B,T 세포 1개에 동일한 모양의 receptor가 많이 있음
      • 한 림프구 = 한 종류의 항원만 인식 (특이성이 있음)
    • 에피토프(epitope)
      • : 항원 표면에서 항원 수용체가 실제로 결합할 수 있는 작은 부분
      • 즉, BCR/TCR 과 결합.

B세포와 T세포의 항원 인식 (Antigen recognition)

    • (좌) B cell, (우) T cell
    • BCR
      • 구조
      • BCR은 Y자 모양의 단백질
      • V 영역(variable region) 이 함께 항원 결합 부위를 만듭
      • 무거운 사슬(heavy chain)과 가벼운 사슬(light chain)로 이루어져 있음
      • 항원을 직접 인식하게 됨
      • 활성화
      • BCR과 항원이 직접 결합 ⇒ B세포 활성화의 초기 단계
      • 활성화된 B세포는 항체(antibody, 또는 면역글로불린 Ig) 를 생성하는 세포로 분화합니다.
      • 항체는 BCR의 용해성(soluable) 형태라고 보시면 됩니다.
      • 항체의 기능
      • 항체는 몸의 체액(혈액, 림프액) 에서 병원체를 직접 공격하거나 중화시키며 방어 기능을 수행합니다.
      • 즉, 항체는 체액성 면역(humoral immunity) 의 핵심입니다.
    • TCR
      • 구조
      • α 사슬(알파 chain) 과 β 사슬(베타 chain)
      • 두 개의 다른 폴리펩타이드로 구성된 이중 구조
      • 활성화
      • 항원을 직접 인식하지 못함
      • 숙주 세포가 제시한 항원 조각을 통해서만 인식할 수 있음
      • 세포가 감염 → 병원체 단백질이 효소에 의해 작은 펩타이드 조각으로 분해됨
      • MHC 분자가 이 펩타이드 조각에 결합
      • → MHC가 세포 표면까지 운반하여 전시(display)함
      • ⇒ 항원 제시(antigen presentation)
  • 1. B cell and T cell development

(1) Large repertoire

    • → 림프구·수용체가 매우 다양함
    • → DNA 재조합(V(D)J)으로 항원 특이성 무한 확장

(2) Self-tolerance

    • → 자기 항원에 반응하지 않도록 조절됨

(3) Proliferation after activation

    • → 항원을 만나면 B세포·T세포가 대량 증식(clonal expansion)

(4) Immunological memory

    • → 기억 세포(memory cell) 생성 → 재감염 시 빠른 반응
  • 2. Generation of diversity (BCR/TCR 다양성 생성)

한 유전자에서 다양한 antibody/TCR 생성 가능

V(D)J gene rearrangement

    • → 여러 segment를 섞어 무수한 조합을 만듦

결과

    • → 한 개의 림프구 = 단 하나의 항원만 정확히 인식
    • → 전체 림프구 집단 = 거의 무한한 항원 인식 가능
  • 3. Origin of self-tolerance (자가 관용의 기원)

림프구는 성숙 과정에서 검사받음

    • B세포 → 골수(bone marrow)
    • T세포 → 흉선(thymus)

Self-reactive cells(자가 항원 반응 림프구) → 제거 또는 비활성화

    • Apoptosis : 아예 죽임
    • Anergy : 기능을 못 하게 만듦

목적

    • → 자기 조직 공격(자가면역)을 막기 위함

  • Proliferation of B cells and T cells (클론 선택·증식)

우리 몸의 림프구 중 특정 에피토프에 맞는 수용체를 가진 림프구는 극히 적음

    • → 하지만 림프절에서 항원은 계속 다양한 림프구와 접촉함
    • → 결국 항원–수용체가 일치하는 림프구를 찾게 됨

항원 수용체가 에피토프와 정확히 결합 → 림프구 활성화 시작

활성화된 B/T 세포는 여러 번 세포 분열 → 동일한 세포들의 클론 형성

    • → 이를 clonal selection(클론 선택)이라고 함
  • 세포 분화 결과
  • 1) Effector cells (단기 작용 세포)

활성화 즉시 항원에 대응하는 세포

B세포 → Plasma cell(형질세포)

    • → 항체를 대량 분비

T세포 → 활성화된 effector T cell (TH, TC 등)

  • 2) Memory cells (장기 생존 기억 세포)

이후 같은 항원 재노출 시 → 빠르게 effector cell로 분화

2차 면역반응(secondary immune response)을 가능하게 함

    • → 더 빠르고 더 강한 면역 반응
  • Clonal selection
  • mmunological memory (면역 기억)

면역 기억 = 이전에 감염된 항원에 대해 장기적 보호를 제공하는 능력

    • → 과거 감염 기록이 남아 있어 재감염 시 빠르게 대응 가능
    • → 평생 또는 수십 년 지속되기도 함
  • Primary immune response (1차 면역반응)

항원을 처음 접했을 때 일어나는 반응

선택된 B세포·T세포가 effector cell로 분화

반응 형성까지 시간이 걸림(느림)

  • Secondary immune response (2차 면역반응)

같은 항원을 다시 만났을 때 일어나는 반응

*Memory cells(기억 세포)**이 즉시 반응

    • → 더 빠르고(fast)
    • → 더 강하고(strong)
    • → 더 오래 지속되는(long-lasting) 면역 반응

Concept 35.3: Adaptive immunity defends against infection of body fluids and body cells

  • Adaptive immunity: humoral vs. cell-mediated immune response
  • 1. Humoral immune response (체액성 면역, B 림프구)

항체(antibody)를 이용해 혈액·림프액에서 독소와 병원체를 중화·제거

B세포 활성화 → 형질세포(plasma cell)로 분화 → 항체 대량 분비

항체는 병원체를 직접 결합·중화하거나 다른 면역세포가 제거하도록 돕는 역할 수행

--

  • 2. Cell-mediated immune response (세포성 면역, T 림프구)

감염된 숙주 세포를 직접 파괴하는 T세포 기반 방어

주로 cytotoxic T cell(세포독성 T세포, TC)이 감염 세포를 살해

  • Helper T cell: activating adaptive immunity
    • → 적응 면역 전체를 활성화하는 핵심 조절자
  • Helper T cell 활성화 과정

TCR이 항원 + MHC II 복합체를 인식하면 helper T cell 활성화

활성화된 helper T cell은 여러 번 분열 → 동일한 세포 클론 형성

생성된 helper T cell 클론은 다음을 활성화함

    • → 적절한 B세포(→ 체액성 면역)
    • → 적절한 T세포(→ 세포성 면역)
    • 즉, helper T cell = humoral + cell-mediated 면역 모두의 출발점
  • The central role of helper T cells *in humoral and cell-mediated immune responses*
  • B cells and antibodies: a response to extracellular pathogens
  • B cells and antibodies: a response to extracellular pathogens
  • → 세포 외 병원체에 대한 체액성 면역 반응
  • 특징

체액성 면역(humoral response)의 핵심 = 클론 선택된 B세포가 항체를 분비하는 것

항체는 혈액·림프액에 분비되어 세포 외 병원체를 표적화

--

  • B cell activation (B세포 활성화)

B세포 활성화에는 helper T cell이 필수적

    • → T_H 세포는 항원 + MHC II를 인식한 뒤 B세포 활성화를 도와 신호 제공

병원체의 표면 단백질(항원) 또한 BCR과 결합하여 활성화에 기여

--

  • Clonal expansion of B cells (클론 확장)

하나의 B세포가 활성화되면 여러 번 세포 분열을 통해 수천 개의 동일한 B세포를 생성

이들 대부분은 plasma cell(형질세포) 로 분화

    • → 항체(면역글로불린)를 대량 분비하여 병원체 제거

--

--

  • B cells and antibodies: a response to extracellular pathogens
    • → 세포 외 병원체에 대한 방어

항체(antibody)는 병원체를 직접 죽이지 않음

    • → 병원체를 표지(marking) 하여 다른 면역 기작이 제거하도록 도움

항체 = 면역글로불린(immunoglobulin, Ig)

    • → 대표적으로 5가지 클래스 존재(IgG, IgA, IgM, IgE, IgD)

--

  • 항체 작용 기전 (Antibody functions)
  • 1) Neutralization(중화)

항체가 바이러스 표면 단백질에 결합

    • → 숙주 세포 침입 자체를 차단

독소(toxin)에 결합해 세포로 들어가는 것을 방지

  • 2) Opsonization-like effect (표적화)

항체가 병원체 표면을 덮어 인식하기 쉽게 만듦

    • → 다른 면역세포가 병원체를 더 효과적으로 제거
  • 3) Complement activation (보체계 활성화)

항원–항체 복합체가 보체(complement) 단백질을 활성화

  • 4) Membrane attack complex(MAC) 형성 → lysis

보체 활성화 후 연속적인 반응(cascade) 발생

병원체 세포막에 구멍(pore) 형성

    • → 외부 물질 유입 → 세포 용해(lysis) 로 제거

Cytotoxic T cells: a response to infected host cells

  • → 감염된 숙주 세포를 제거하는 세포성 면역 반응
  • 역할

세포성 면역(cell-mediated response)의 중심

감염된 세포가 제시하는 항원 조각을 인식하고 독성 단백질을 사용해 감염 세포를 직접 사멸시킴

--

  • 인식 과정 (Recognition)

세포독성 T세포(CTL)는 감염된 세포 내부에서 생성된 항원 펩타이드 조각을 인식

감염된 세포는 class I MHC에 항원 조각을 결합해 세포 표면에 제시

세포독성 T세포는 TCR + 보조 단백질(CD8) 을 이용해

    • → 항원 + MHC I 복합체에 특이적으로 결합

--

  • 3. 활성화된 Cytotoxic T cell의 작용 (Killing mechanism)

활성화된 CTL은 표적 세포(target cell) 막을 파괴하는 단백질을 분비

    • → perforin(막에 구멍을 만드는 단백질)
    • → granzymes(세포사멸을 유도하는 효소)

이 과정은 표적 세포에 세포사멸(apoptosis) 을 유도

    • → 감염 세포를 깔끔하게 제거하여 주변 조직 피해를 최소화
  • OVERVIEW

  • Immunization (면역접종)

2차 면역반응에서 나타나는 빠르고 강한 보호 효과를 기반으로 함

항원을 체내에 인위적으로 도입하여 적응 면역을 유도

    • → B세포·T세포 활성화
    • → memory cell(기억 세포) 형성

결과적으로 이후 실제 병원체를 만났을 때 빠른 2차 면역반응 유도

  • Active vs. Passive immunity (능동 면역 vs. 수동 면역)

--

  • 1) Active immunity (능동 면역)

병원체 감염 또는 면역접종(immunization) 에 의해

    • → 체내에서 직접 면역반응이 일어나는 경우

B세포·T세포 활성화 → effector cell + memory cell 생성

지속적인 면역 형성 가능

--

  • 2) Passive immunity (수동 면역)

한 개체에서 생성된 항체를 직접 전달받아 얻는 면역

개체 스스로 면역반응을 일으키지 않음 → memory cell 형성 X

일시적 보호에 효과적

  • Disruptions in immune system function
  • → 적응 면역이 강력하지만 완벽하지는 않음
  • 1. Allergies (알레르기)

알레르기 = 알레르겐(allergen)에 대한 과민(hypersensitive) 면역 반응

형질세포(plasma cell) → 꽃가루 표면 항원에 특이적인 항체 분비

항체–항원 결합 → 결합조직의 면역세포가 히스타민(histamine) 등 염증 물질 분비

항히스타민제(anti-histamine) → 히스타민 수용체 차단 → 알레르기 증상 완화

급성 알레르기 반응은 아나필락시스 쇼크(anaphylactic shock) 로 이어질 수 있으며, 생명을 위협

과민반응을 가진 사람들은 응급 대처용으로 에피네프린(epinephrine) 을 휴대하기도 함

  • Autoimmune diseases (자가면역질환)

자가면역질환은 면역계가 자기 몸의 분자·조직을 공격하는 상태

대표적 질환

    • → Systemic lupus erythematosus(전신홍반루푸스)
      • 전신의 다양한 조직에서 자가항체가 면역복합체를 형성
    • → Type 1 diabetes(제1형 당뇨병)
      • 면역계가 베타세포 죽임
    • → Multiple sclerosis(다발성 경화증)
      • 면역계가 중추신경계의 미엘린을 공격하여 신경전달을 방해
    • → Rheumatoid arthritis(류마티스 관절염)
      • 면역계가 관절막을 공격
  • mmune System Avoidance (면역 회피)
  • HIV와 AIDS

HIV(human immunodeficiency virus)는 적응 면역계의 핵심인 helper T cell을 공격

바이러스 증식 + 감염된 세포의 사멸 → helper T cell 감소

결과: 후천성 면역결핍증(AIDS) 발생

HIV는 완치 불가하지만,

    • → 바이러스 복제 억제, AIDS 진행 속도 감소하는 약물 치료가 개발됨
  • cf) SCID (severe combined immunodeficiency)

유전적 결함으로 B세포·T세포가 모두 기능하지 못하는 중증 면역결핍증
