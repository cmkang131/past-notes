Concept 14.1: Genes specify proteins via transcription and translation

The flow of genetic information

    • central dogma(중심 원리) : DNA → RNA → Protein

    • Genotype : 생물체가 가지고 있는 DNA 염기서열
    • phenotype : 실제로 드러나는 생물의 특징
    • 검은색 머리, 밤색 머리를 만드는 유전자는 동일한 유전자, 버전은 다름.

      • Gene expression : DNA 정보가 단백질로 만들어지는 과정
      • transcription(전사), translation(번역)을 통해 단백질 만듦

Beadle and Tatum’s experiments and hypothesis

    • “하나의 유전자는 하나의 효소를 지정한다” ⇒
    • 영양 결핍 돌연변이가 생긴 빵곰팡이를 최소 배지(minimal medium)에서 자랄 수 있는지 실험.
    • → 돌연변이 곰팡이는 스스로 필요한 영양소(아미노산 등)를 만들지 못함
      • → 최소 배지에서는 자라지 못한다는 것을 확인.
    • = One gene – one enzyme hypothesis
      • or One gene – one transcription hypothesis
  • T-RNA
    • 아미노산을 리보솜으로 운반하는 RNA
    • 1. mRNA의 염기서열을 3개씩(코돈 단위) 읽고,
    • 2. 그 코돈에 맞는 아미노산을 리보솜으로 가져와,
    • 3. 폴리펩타이드(단백질) 사슬이 만들어지도록 합니다.
  • R-RNA
    • RNA 단백질 복합체 → tRNA가 가져온 아미노산을 연결
      • 1. 리보솜이 mRNA를 따라가면서 코돈을 읽고,
      • 2. 각 코돈에 맞는 tRNA를 받아,
      • 3. 아미노산들을 펩타이드 결합(peptide bond)으로 이어줍니다.
    • → 뒤에 tRNA, rRNA 설명이 또 있음

Basic Principles of Transcription and Translation

    • RNA는 리보스를 가짐, 유라실(U)이 타민(T)을 대신
    • RNA는 일반적으로 single-stranded.
    • Transcription : RNA를 만드는 과정 ← DNA 정보를 이용
      • messenger RNA (mRNA)를 만듦
    • Translation : mRNA를 이용해 폴리펩타이드(단백질)을 만듦
      • 리보솜 = mRNA코돈을 읽고, tRNA가 아미노산을 운반하여 단백질 사슬을 만듦.
    • 세포 종류에 따른 차이
      • 원핵생물(Bacteria):
      • 전사와 번역이 동시에 일어남 (핵이 없어서 RNA가 곧바로 번역됨)
      • 진핵생물(Eukaryotes):
      • 전사: 핵(nucleus) 안에서 일어남
      • RNA(primary transcripts)가 그대로 쓰이지 않고,
      • modify(가공)을 거쳐 mRNA가 됨.
      • 번역: 세포질(cytoplasm)에서 일어남
  • The genetic code

  • Triplet code
    • 뉴클레오타이드 염기 3개가 한 조합
  • codon
    • 3개의 염기 조합 (RNA, DNA)
  • Template strand (주형가닥)
    • mRNA를 전사하기 위해 이용된 가닥(mRNA와는 반대로 되어있음)
  • Coding strand (비주형가닥)
    • mRNA와 동일한 코드를 가지고 있는 가닥

Cracking the code

  • 코돈은 mRNA의 염기 3개씩 한 세트를 이뤄 하나의 아미노산을 지정
  • 그런데 읽는 시작점이 바뀌면 3개씩 묶이는 reading frame이 완전히 달라질 것.
  • → reading frame이 정확히 유지되어야 올바른 폴리펩타이드가 만들어짐.
  • The genetic code is nearly universal, shared by all organisms on earth.
    • AUG는 항상 메치오닌을,
    • UAA, UGA, UAG는 항상 번역 종료 신호를 의미함.
  • 담뱃잎에 반딧불이 유전자를 삽입했더니 빛이 남.

Concept 14.2: Transcription is the DNA-directed synthesis of RNA: a closer look

Transcription

    • ### RNA polymerase
    • *RNA 중합효소(RNA polymerase)**는 DNA 염기서열을 이용해 RNA를 합성하는 효소입니다.
    • “DNA-dependent”는 DNA를 주형(template)으로 삼는다는 뜻이에요.
    • 5’ → 3’ 방향으로 RNA를 합성하며, 프라이머(primer) 없이 바로 시작할 수 있습니다.
    • ### Promoter
    • *프로모터(promoter)는 RNA polymerase가 붙는 DNA의 특정 서열(시작 신호)**입니다.
    • 즉, 전사가 어디서 시작될지를 알려주는 구간이에요.
    • ### Terminator (in bacteria)
    • *터미네이터(terminator)는 전사가 끝나는 위치를 알려주는 서열**입니다.
    • RNA polymerase가 이 지점에 도달하면 RNA 합성이 멈춥니다.
    • ### Transcription unit
    • *전사 단위(transcription unit)는 실제로 RNA로 복사되는 DNA 구간 전체**를 말합니다.
      • (즉, 한 유전자에 해당하는 DNA 영역)
    • ### 3 stages of transcription
    • 전사는 세 단계로 진행됩니다.
    • 1. Initiation (개시): RNA polymerase가 프로모터에 결합하고 전사가 시작됨
    • 2. Elongation (신장): RNA 사슬이 5’→3’ 방향으로 길어짐
    • 3. Termination (종결): RNA 합성이 종료되고 전사체가 떨어져 나옴
    • ### Transcription factors & initiation complex (진핵세포)
    • RNA polymerase는 DNA 서열에 잘 붙지 못함.
      • → 전사 인자(transcription factors)(단백질)는 RNA polymerase가 프로모터에 정확히 붙도록 도움
    • RNA polymerase와 여러 전사 인자들이 프로모터에 모여 만들어진 전체 구조를
      • transcription initiation complex (전사 개시 복합체)라고 합니다.
    • ### TATA box
    • 진핵생물에서 프로모터의 핵심 서열로, “TATAAA” 형태의 염기서열이 포함됩니다.
    • 이 부분이 RNA polymerase가 인식 복합체를 형성하는 데 결정적인 역할을 합니다.
  • [termination]
  • (세균에서) 중합효소는 터미네이터(terminator)의 끝에서 전사를 멈춘다.
    • →mRNA가 추가 가공 없이 바로 번역될 수 있음.
  • (진핵생물에서) RNA 중합효소 II는 폴리아데닐화 신호 서열(polyadenylation signal sequence)을 전사한다.
    • → RNA가 가공되어 mRNA가 됨

Concept 14.3: Eukaryotic cells modify RNA after transcription

  • 원핵, 진핵 차이
  • 전사와 번역이 동시에 일어날 수 있음(RNA) ↔ DNA는 전사 후에 번역
  • DNA에서 나온 RNA는 modify해야지 이용할 수 있음

RNA processing

  • 진한색, 엑손 → 단백질과 매칭되는 코돈
  • 연한색, 인트론 → 염기서열로 구성되어 있지만 단백질로 만들어지지 않음
    • → 인트론 부분은 필요 없으니 잘라서 버리고, 남은 엑손을 공유결합으로 순서대로 연결
    • = 스플라이스
  • 3’, 5’ 끝이 손상될 수 있음
  • → 구아닌, 아데닌 뉴클레오타이드를 붙여줘서 보호해야 함. (5’Cap, Poly-A tail)
    • **중요한 게 있을 수록 tail이 길어짐을 관찰함.
  • modified RNA가 mRNA가 됨.
  • 5’ UTR은 리보솜이 단백질을 만들기 시작하기 위한 위치.

Concept 14.4: Translation is the RNA-directed synthesis of a polypeptide: a closer look

Translation

  • tRNA
    • 아미노산을 리보솜으로 운반
    • 각 tRNA는 특정 mRNA 코돈에 대응하는 특정 아미노산을 운반함.
    • L자 구조
      • L자의 한쪽 끝 : 아미노산 결합 부위
      • 다른 끝 : 안티 코돈(특정 코돈에 반대인 코돈)
  • 리보솜과 rRNA
    • 단백질 합성은 리보솜에서 일어남.
    • 리보솜은 단백질과 리보솜 RNA(rRNA)로 구성됨.
    • 리보솜에는 큰 소단위(large subunit), 작은 소단위(small subunit)가 있으며 함께 작동해 tRNA가 가져온 아미노산들을 펩타이드 결합으로 연결함
  • Translation: elongation(신장)
    • 리보솜이 mRNA를 따라 이동하며 아미노산을 하나씩 추가함.
    • 이 과정은 elongation factors(신장 인자)라는 단백질들의 도움을 받아 진행되며 3단계로 나눌 수 있음
    • 1. 코돈 인식 : A자리에 새 tRNA가 들어와, mRNA의 코돈과 상보적으로 결합
    • 2. 펩타이드 결합 형성 : P 자리에 있는 폴리펩타이드 사슬이 A자리에 있는 새 아미노산과 펩타이드 결합을 형성
    • 3. Translocation(전이) : 5’ → 3’ 방향으로 이동, A 자리에 있던 tRNA가 P자리로 이동

after transalation

  • 그냥 방치되지 않고 적절히 접히고, 가공되고, 세포 내 특정 위치로 운반
  • 1. 소포체(ER)내에서 3차 구조로 접힘
  • 2. glycosylation(당 결합), lipidation(인지질 결합), phosphorylation(인산화) 등 화학적 변화
  • 3. 단백질의 목적지 지정 (Protein targeting)

Coupled Transcription and Translation in Bacteria

  • Bacteria vs. Eukaryotes
  • 공통점
    • 하나의 유전자에서 여러 개의 mRNA가 전사될 수 있음
  • Bacteria(원핵 세포)
    • 전사, 번역이 동시에 일어남.
    • → 핵이 없기 때문에 mRNA만들어지자마자 리보솜이 붙어 단백질 합성이 시작됨
    • 하나의 mRNA에 여러 개 단백질 지정하는 poly-cistronic mRNA가 형성
  • Eukaryotes (진핵세포)
    • 핵막이 전사와 번역을 물리적으로 분리함.
    • → 전사는 핵 안에서 발생, mRNA는 processing 이후 세포질로 이동하여 번역이 발생.
    • 대부분의 mRNA는 하나의 단백질을 지정하는 mono-cistronic 구조를 가짐.

Concept 14.5: Mutations of one or a few nucleotides can affect protein structure and function

  • Mutations(돌연변이) → DNA염기서열의 변화 (DNA 복제 or 자외선 등의 영향)

Mutations

  • 1. Point Mutation
    • 한 염기쌍 (nucleotide pair)이 화학적으로 변하는 돌연변이
  • 2. 돌연변이의 2가지 주요 형태
    • 1. Single nuclotide-pair substitution (염기 치환 돌연변이)
      • → 한 염기가 다른 염기로 바뀜
    • 2. Nuclotide-pair insertion or deletion (삽입 또는 결실 돌연변이)
      • → 한 염기가 삽입되거난 삭제됨.
  • 3. Substitution Muations (염기 치환 돌연변이의 종류)
    • Silent : 코돈이 바뀌었지만 같은 아미노산을 지정 (유전 암호의 중복성 때문)
    • Missense : 하나의 아미노산 변경 → 단백질 기능이 변하거나 손상될 수 있음
    • Nonsense : 아미노산 코돈이 정지 코돈으로 바뀜 → 단백질이 짧게 끊겨 기능이 사라짐.
  • 4. Insertion / Deletion Mutations (삽입, 결실 돌연변이)
    • Frameshift Mutation (프레임 이동 돌연변이)
      • → 코돈은 3개 염기씩 읽히는데, 염기가 하나라도 삽입되거나 빠지면 이후 모든 코돈 구성이 바뀜
      • → 완전히 잘못된 아미노산 서열 생성
  • 돌연변이의 원인
  • 1. 자발적 (spontaneous) 돌연변이
    • → DNA 복제 중 오류가 자연적으로 발생
    • 복제 효소의 교정(proofreading)이 실패할 경우 축적됨
  • 2. 유발(mutagenic) 돌연변이
    • → 물리, 화학적 요인(mutagens)에 의해 발생
      • ex) 자외선(UV), 방사선, 화학물질 등. 특히 발암물질
