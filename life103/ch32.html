Concept 32.1: Animal form and function are correlated at all levels of organization

Levels of organization in animals

  • 형태(anatomy) : 생물체의 구조
  • 기능(physiology) : 구조가 실제로 어떤 일을 수행하는지

  • 조직(tissue) : 비슷한 모양과 기능을 가진 세포의 모임 → 역할을 수행하는 단위
  • 기관(organ) : 여러 종류의 조직 모임 → 복잡한 기능을 수행하는 구조입니다
  • 기관계(organ system) : 여러 기관이 협력 → 생명 유지에 필요한 큰 기능을 담당
  • 동물 세포와 조직은 아래 네 유형으로 분류됨.
    • 상피(표피) 조직(epithelial tissue)
    • 결합 조직(connective tissue)
    • 근육 조직(muscle tissue)
    • 신경 조직(nervous tissue)
      • ⇒ 네 조직이 조합/배치되어 동물의 형태와 기능이 완성됨.

Concept 32.2: The endocrine and nervous systems act individually and together in regulating animal physiology

Regulating animal physiology

  • 내분비계(endocrine system), 신경계(nervous system)의 신호 전달 방식
구분 **내분비계** **신경계**
신호 분자 호르몬 신경전달물질
이동 경로 혈액을 통해 전신 뉴런 축삭을 따라 특정 표적
전달 속도 상대적으로 느림 매우 빠름
지속 시간 지속적 비지속적
작용 범위 넓음(전신) 좁음(특정 세포)
반응 조건 수용체를 가진 세포만 반응 시냅스에 연결된 표적세포만 반응

Regulation of the internal conditions in animals

  • 세포 : 혈액과 조직액(interstitial fluid) 속에 살아감
    • 용질 농도, 이온 균형, 삼투압, pH 등이 일정해야 세포가 정상적으로 기능함

항상성(Homeostasis)

    • 외부 환경이 변해도 내부 환경을 일정하게 유지하려는 능력
      • = steady state : 안정된 상태 유지
        특정 변수(체온, pH, 혈당)을 set point 근처로 유지, 벗어나면 조절
    • 체온 조절(Thermoregulation)
      온도 변화에 민감, 체온을 정상 범위 내에서 유지
      • 내온성(endothermic) 동물
      • 대사 활동 → 스스로 열 생성
        예: 조류(새)와 포유류
        장점: 외부 온도와 무관하게 활동성을 유지
        단점: 많은 에너지(먹이) 필요함
      • 외온성(ectothermic) 동물
      • 외부 환경에서 열을 얻음
        예: 곤충, 어류, 양서류, 파충류 등
        장점: 에너지 소모 적음
        단점: 주변 온도에 따라 활동 속도와 대사율 변함

Concept 32.4: A shared system mediates osmoregulation and excretion in many animals

A shared system mediates osmoregulation and excretion in many animals.

  • 하나의 공통된 시스템이 삼투조절과 배설을 모두 담당

Osmoregulation (삼투조절)

    • Osmolarity (삼투질 농도)
      • : 용액 속 용질의 농도, → 물의 이동 방향을 결정
    • 조직액의 용질 농도를 조절 → 물의 유입과 손실을 관리

Excretion (배설)

    • 대사 과정에서 질소 노폐물(ammonia, urea, uric acid 등)과 기타 부산물 제거
    • 삼투 조절과 배설은 같은 기관(콩팥)에서 일어남 → shared system
    • Urea (요소)
      • : 암모니아보다 훨씬 덜 독성, 물이 부족한 육상 환경에서 안전하게 저장/배출

Excretory processes — 배설 과정의 핵심 흐름

  • 몸속 체액에서 filtrate(여과액) 생성 → 여과액을 정제(refining) → 질소 노폐물이 포함된 배설물을 몸 밖으로 내보냄
  • 1. Filtration — 여과 [glomerulus, 사구체]
    • 몸속 채액(특히 혈장) → 모세혈관에서 압력에 의해 여과막을 통과
      • → 큰 분자(단백질, 혈구) 통과 X, 물 + 작은 용질(이온, 포도당, 아미노산, 요소) 여과액으로 들어감
  • 2. Reabsorption — 재흡수
    • 여과액이 배설관을 지나며 필요한 물질을 흡수
      예: 포도당, 아미노산, Na+, Cl-, 물
  • 3. Secretion — 분비 ‘
    • 여과 과정에서 빠져나오지 못했던 불필요한 물질 (독성 물질, 약물, 추가 이온 등)
      • 혈액 → 여과액 방향으로 능동적으로 밀어 넣음
  • 4. Excretion — 배설
    • 최종적으로 여과액은 urine(소변)이 되어 배출
    • 질소 노폐물(주로 요소)가 포함됨

Concept 32.5: The mammalian kidney’s ability to conserve water is a key terrestrial adaptation

The mammalian kidney

    • 콩팥의 기본 단위: 네프론(nephron)
    • 여과액(filtrate)의 생성 위치
      • 혈액이 사구체(glomerulus)를 통과 → 압력으로 여과
      • 여과액은 Bowman’s capsule(보우만주머니) 내부 공간으로 이동
      • 즉, 혈액 → 사구체 여과 → Bowman’s capsule → 여과액 형성
    • 하루 약 1,600L의 혈액이 콩팥을 통과, 이 중 180L의 초기 여과액 생성
      • → 대부분이 재흡수 됨
    • 재흡수(reabsorption)의 중요성
      • 물, 포도당, 아미노산, 비타민 등 혈액으로 돌아감. 최종적으로 1.5L만 소변이 됨

Coordination of kidney(신장) regulation

    • RAAS(레닌-안지오텐신-알도스테론 시스템) → 콩팥의 기능을 조절
    • RAAS(레닌–안지오텐신–알도스테론 시스템)
      • 혈액량 or 혈압이 떨어짐 → RAAS 활성화
      • 1. 콩팥 → 레닌(renin) 분비
      • 신장(kidney)/ blood pressure sensor → renin을 분비
      • 2. renin → Angiotensin II 생성
      • Angio = 혈관, tensin = 수축시킴
      • Angiotensinogen → Angiotensin I
      • +ACE(폐의 효소)→ Angiotensin II(active, 호르몬)
      • 3. Angiotensin II의 작용
      • (1) 전신 혈관 수축
      • (2) 콩팥의 모세혈관 혈류 감소 → Na+, 수분 재흡수를 증가시킴
      • (1) + (2) ⇒ 혈압 증가
