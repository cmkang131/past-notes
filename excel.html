  • 숫자 필드는 기본이 합계 → 값 우클릭 → 값 필드 설정 → 개수 / 평균

  • 비율: 값 필드 설정 → 값 표시 형식 → 열 합계 비율 / 행 합계 비율
  • 같은 필드를 값에 두 번 넣으면 금액과 비율을 나란히 볼 수 있음

  • Yes/No 같은 텍스트 필드를 값에 넣으면 자동으로 개수
  • 특정 값만 보기: 그 필드를 필터 칸에 넣고 드롭다운에서 Yes만 선택 → 남은 데이터 안에서 비율이 다시 계산됨
  • "무엇이 더 중요한 요인인가"류 질문: 요인을 행에, 결과(Yes/No)를 열에 두고 행 합계 비율 → 요인의 값마다 Yes 비율이 얼마나 벌어지는지 비교 (차이가 큰 쪽이 더 중요)

날짜와 조회 함수 (Bakery)
  • 요일 번호: =WEEKDAY(G12,2) → 월=1 … 일=7
  • 두 번째 인수: 1 = 일요일 1 … 토요일 7 / 2 = 월요일 1 … 일요일 7 / 3 = 월요일 0 … 일요일 6
  • 요일 이름: =VLOOKUP(F12,$A$13:$B$19,2,FALSE) → A13:B19에 1~7과 요일 이름 표를 만들어 둠
  • 월: =MONTH(G12) → =VLOOKUP(N12,$A$22:$B$33,2,FALSE)로 월 이름

슬라이드: VLOOKUP 인수 네 개. 찾을 값 / 표 (그 첫 열에서 찾음) / 몇 번째 열을 돌려줄지 (시트가 아니라 표 왼쪽부터 셈) / FALSE·0 = 정확히 일치, TRUE·1 = 근사 (생략하면 근사). 오른쪽 예: WEEKDAY로 나온 요일 번호를 "1~7, 요일 이름" 두 열짜리 표(이름 lookday)에서 찾아 2번째 열 → 2면 Tuesday.

  • VLOOKUP(찾을 값, 표, 몇 번째 열, FALSE): 표의 첫 열에서 찾고, 표 왼쪽부터 센 열의 값을 줌

슬라이드: HLOOKUP = VLOOKUP을 옆으로 돌린 것. 예: 5강 묶음 모형에서 윗행에 상품 번호 1~7, 아랫행에 가격 → 손님이 산 번호(L6)로 그 가격을 찾음, 0이면 안 산 것이라 0. 표 범위를 $로 안 묶으면 77명 아래로 끌 때 표가 같이 내려가서 둘째 줄부터 틀림. 표가 진짜 가로로 놓일 때만 HLOOKUP.

  • HLOOKUP: 같은 함수인데 첫 행에서 찾고 아래 몇 번째 행 값을 줌 → 표가 가로로 놓였을 때 (Verizon 가격표)

슬라이드: 넷째 인수 비교. FALSE/0 정확히 일치: 없으면 #N/A, 정렬 필요 없음, 거의 항상 이것 (기본값이 아니라 직접 써야 함). TRUE/1 근사: 찾는 값 이하 중 가장 큰 항목, 첫 열이 오름차순이 아니면 조용히 틀림, 세율·수량 할인·학점 구간표용. 아래 흔한 오류 넷: #N/A (값이 없거나 공백, 숫자가 텍스트) / 엉뚱한 열 (열 번호를 시트 기준으로 셈) / 복사하면 틀어짐 (표를 $로 안 묶음) / 조용히 틀린 값 (근사 일치 + 정렬 안 된 표).

  • 마지막 인수: FALSE/0 = 정확히 일치, TRUE/1 = 비슷한 값 → 교수님: "거의 항상 정확히 일치"
  • 표 범위는 F4로 고정해야 아래로 끌 때 안 밀림
  • MATCH(값, 범위, 0): 범위에서 몇 번째인지 → =MATCH("Pies",$H$11:$L$11,0) = 2
  • 마지막 인수: 0 = 정확히 일치 (수업은 항상 0) / 1 = 찾는 값 이하 중 가장 큰 값 (오름차순 정렬 필요) / −1 = 이상 중 가장 작은 값 / 생략하면 1 → Verizon에서 학생들 매출이 달랐던 원인
  • INDEX(표, 행, 열): =INDEX(H12:K17,2,2) → 2행 2열 값 / 행에 0을 넣으면 그 열 전체
  • MATCH, INDEX로 AVERAGEIFS 열을 고르는 식은 숙제 문제라고 함

슬라이드: 가장 흔한 실수인 인수 순서. SUMIF(조건 범위, 조건, 합계 범위)는 합계 범위가 셋째, SUMIFS(합계 범위, 조건 범위1, 조건1, …)는 첫째. AVERAGEIF와 AVERAGEIFS도 같은 구조. COUNTIF·COUNTIFS는 요약할 열이 없어서 범위와 조건 쌍만 씀.

  • SUMIF/AVERAGEIF는 요약 범위가 마지막, SUMIFS/AVERAGEIFS는 맨 앞
  • AVERAGEIFS는 모든 범위가 같은 모양이어야 함 (여러 열짜리 표를 평균 범위로 넣으면 에러)

  • 설정 세 가지: 목표 셀 (최대/최소/지정값) / 변수 셀 (여러 칸 가능) / 제약 (추가 버튼)
  • 순서: ① 목표 설정 셀 ② 최대값 ③ 변수 셀 변경 (Verizon은 D3:J3 드래그) ④ 추가 → 셀 참조 D3:J3, <=, 100 → 추가 → >=, 0 → 확인 ⑤ "제한되지 않는 변수를 음이 아닌 수로 설정" (기본 체크) ⑥ 해법 선택 ⑦ 해 찾기 → Evolutionary는 오래 걸리니 기다림
  • 해법은 문제에서 알려줌 (교수님)
  • 변수 셀이 떨어져 있으면 "변수 셀 변경" 칸에 쉼표로 입력 ($G$8,$G$20) 또는 Ctrl(맥은 Cmd) 누른 채 클릭
  • 거듭제곱 수요 로 해 찾기를 돌릴 때: 가격 셀이 0이면 0의 음수 제곱이라 #DIV/0! → 가격 시작값을 현재 가격 같은 양수로 두고 돌리기, 결과가 이상하면 시작값 바꿔 한 번 더
  • 선형·거듭제곱을 둘 다 묻는 문제는 수량 식만 다르고 이익 식·해 찾기 설정은 같음 → 시트를 복사해서 수량 셀만 바꾸면 됨
  • "제한되지 않는 변수를 음이 아닌 수로" 체크 = 가격 ≥ 0
  • 면도기: 목표 G11 최대, 변수 G8, GRG 비선형 (날 이익까지 넣을 땐 목표만 G15로)
  • 퀴즈 예고 대비: 날 가격·날 원가가 따로 주어지면 날 이익 = (날 가격 − 날 원가) × 날 개수, 변수 셀 2개 (면도기 가격, 날 가격)
  • 날에도 탄력성이 주어지면 날 개수도 고정값이 아니라 날 가격의 함수 → 면도기 때와 같은 방법(현재 점 + 탄력성 → 두 번째 점 → 추세선)으로 날 수요식을 만들고 그 식을 셀에 넣기
  • 보완재가 "주상품 k개당 1개" 식으로 주어지면 보완재 수량 = 주상품 수량 ÷ k (면도기는 반대로 × 50)
  • 이익 식은 (P−C)*Q처럼 아무 형태로 써도 됨 (교수님)
  • 정수 제약: 제약 추가에서 int → 단, 면도기 수요처럼 다른 셀의 함수인 셀은 정수로 못 묶음 (교수님 시연)
