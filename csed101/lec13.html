Recursion(재귀)
Recursive Function(재귀 함수)는 Function(함수)가 자기 자신을 호출하여 문제를 해결하는 프로그래밍 기법
  • 함수가 자신을 호출하면서 호출 횟수를 제한하는 조건문 필요
  • 장점 : 반복문보다 간결한 코드
  • 단점 : Stack(스택) 메모리 사용 → 메모리 사용량 증가
    • 실행 속도 저하
Example(message) 
def message(times):
      print("times : ", times)
      if times > 0 :
            print("This is a recursive function.")
            message(times - 1)

Example(resursive_sum) 
#1부터 n까지의 합을 구하는 함수를 재귀적으로 구현
def recursive_sum(n):
    print('n=', n)
    if n == 1:
        return 1
    else:
        return n + recursive_sum(n-1)

n = 10
print(recursive_sum(n))

# recursive_sum은 매개변수 n이 1인 경우에는 1을 반환하고, 
# 그렇지 않은 경우에는 n과 recursive_sum(n-1)의 합을 반환
# recursive_sum(n-1)은 n보다 작은 정수들의 합을 구하는 재귀적인 호출을 수행
Example(Factorial) 
def Factorial(n):
    if n == 1:
        return 1
    else:
        return n * Factorial(n-1)

n = 4
print(n, "! =", Factorial(n))

# factorial(4) 호출
# 4 * factorial(3) 호출
# 4 * 3 * factorial(2) 호출
# 4 * 3 * 2 * factorial(1) 호출
# 4 * 3 * 2 * 1 = 24 반환
Example(Fibonacci numbers) 
# Fibonacci: 각 숫자가 이전 두 수의 합인 수열
def Fibonacci(n):
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        return Fibonacci(n-1) + Fibonacci(n-2)

for i in range(10):
    print(Fibonacci(i))
Example(Hanoi Tower)
  • > 입력 조건
    • n = 3 (원반 3개)
    • from_peg = 'A' (출발 기둥)
    • to_peg = 'C' (목적지 기둥)
    • aux_peg = 'B' (보조 기둥)
    • 실행 순서
    • 1.n-1개의 원반을 보조 기둥(aux_peg)으로 옮긴다.
    • 2.가장 큰 원반(n번 원반)을 목적지 기둥(to_peg)으로 옮긴다.
    • 3.n-1개의 원반을 보조 기둥(aux_peg)에서 목적지 기둥(to_peg)으로 옮긴다.
def hanoi_tower(n, from_peg, to_peg, aux_peg):
    if n == 1:
        # 재귀 종료 조건: 원반이 1개면 단순히 이동
        print(f"Move disk 1 from {from_peg} to {to_peg}")
        return

    # Step 1: n-1개의 원반을 보조 기둥(aux_peg)으로 이동
    hanoi_tower(n - 1, from_peg, aux_peg, to_peg)

    # Step 2: 가장 큰 원반을 목적지 기둥(to_peg)으로 이동
    print(f"Move disk {n} from {from_peg} to {to_peg}")

    # Step 3: n-1개의 원반을 목적지 기둥(to_peg)으로 이동
    hanoi_tower(n - 1, aux_peg, to_peg, from_peg)
  • 최소 이동 횟수 : 2^n - 1
