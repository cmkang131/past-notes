TUI vs GUI
  • TUI (Text-based User Interface)와 GUI (Graphical User Interface)는 사용자와 컴퓨터 간의 상호작용을 위한 두 가지 주요한 인터페이스 유형
  • TUI
    • 장점: 자원 소모 적음, 텍스트 기반 → 콘솔 환경에서 가능
    • 단점: 사용자가 명령어 옵션을 기억하고 입력해야 함, 시각적 표현 어려움
  • GUI
    • 장점: 시각적인 요소를 통해 사용자에게 직관적인 환경을 제공
    • 단점: 자원 소모가 많고 용량이 큰 경우가 있음, 플랫폼에 호환이 떨어질 수 있음
Python GUI - Tkinter # GUI Method(메서드)는 기말 범위 X
  • tk.—-(self.window, b, c)
  • Label (레이블): 사용자에게 텍스트나 이미지를 표시
  • Button (버튼): 사용자가 클릭할 수 있는 버튼
  • Entry (입력 필드): 사용자로부터 텍스트를 입력받을 수 있는 상자
  • Checkbutton (체크 박스): 사용자가 체크할 수 있는 옵션을 표시, 여러 개의 체크 박스를 그룹으로 묶어 다중 선택 가능
  • Radiobutton (라디오 버튼): 여러 개의 옵션 중 하나를 선택할 수 있는 버튼, 여러 개의 라디오 버튼을 그룹으로 묶어 단일 선택 가능
  • Listbox (list(리스트) 박스): 여러 항목을 리스트 형태로 표시하고 사용자가 선택할 수 있도록 하며, 단일 선택과 다중 선택이 가능
  • Combobox (콤보 박스): 텍스트 상자와 드롭다운 목록을 결합한 Widget(위젯), 사용자가 선택할 수 있는 목록을 제공하며, 자유롭게 텍스트 입력 가능
  • Text (텍스트 상자): 여러 줄의 텍스트를 입력받거나 표시하는 데 사용, 대용량 텍스트의 편집이 가능하며 스크롤바 포함 가능
Example (StackGUI) 
tk.Tk() => Tkinter 창 생성
self.window.title('Stack Example') => 창 제목 생성
tk.Entry(self.window) => 엔트리 생성
self.input_entry.get() => 엔트리 입력 값 get
self.input_entry.delete(0, tk.END) => 입력 창 초기화 (0~끝까지)
tk.Button(self.window, text= '', command=function) => 버튼 생성
self.stack_label.config(text=stack_text) => config -> label 변경

self.window.mainloop() =>  창 실행
import tkinter as tk

class StackGUI:
    def __init__(self):
        self.stack = []

        self.window = tk.Tk() # Tkinter 창 생성
        self.window.title('Stack Example') # 창 제목 설정

        #입력창과 버튼 생성
        self.input_entry = tk.Entry(self.window)
        self.input_entry.pack() # -> 레이아웃에 배치하여 화면에 보이게 함

        self.push_button = tk.Button(self.window, text = 'push', command=self.push)
        self.push_button.pack()

        self.pop_button = tk.Button(self.window, text = 'pop', command=self.pop)
        self.pop_button.pack()

        # 스택 출력을 위한 레이블 생성
        self.stack_label = tk.Label(self.window, text='Stack: ')
        self.stack_label.pack()

    def push(self):
        item = self.input_entry.get() # 입력 창에서 값을 가져옴
        if item:
            self.stack.append(item) #스택에 값 추가
            self.update_stack_label() #스택 레이블 업데이트
            self.input_entry.delete(0, tk.END) #입력창 초기화
        
    def pop(self):
        if self.stack:
            self.stack.pop() #스택에서 값 제거
            self.update_stack_label() #스택 레이블 업데이트

    def update_stack_label(self):
        stack_text = 'Stack: ' + ','.join(self.stack) # 스택 내용을 문자열로 변환
        self.stack_label.config(text=stack_text)
        
    def run(self):
        self.window.mainloop() # 창 실행

stack_gui = StackGUI()
stack_gui.run()
Example (Bubble Sort(버블 정렬) GUI)
  • Tkinter을 사용하여 버블 소트 예제 구현
  • 숫자 입력 후 ‘add’ 버튼 클릭 → 숫자를 리스트에 추가
  • Sort(정렬)버튼 ⇒ 버블 소트 알고리즘 사용하여 정렬
  • 결과는 Sorted Data 라벨에 표시
import tkinter as tk

class BubbleSortGUI:
    def __init__(self):
        self.stack = []

        self.window = tk.Tk()
        self.window.title('BubbleSort Example')

        self.input_entry = tk.Entry(self.window)    
        self.input_entry.pack()    

        self.add_button = tk.Button(self.window, text='Add', command=self.add)
        self.add_button.pack()

        self.sort_button = tk.Button(self.window, text='Sort', command=self.sort_fn)
        self.sort_button.pack()

        self.sorted_label = tk.Label(self.window, text = 'list ')
        self.sorted_label.pack()


    def add(self):
        item = self.input_entry.get()
        if item:
            self.stack.append(int(item))
            self.stack_label_update()
            self.input_entry.delete(0, tk.END)

    def sort_fn(self):
        for j in range(len(self.stack)-1):
            for i in range(len(self.stack)-j-1):
                if self.stack[i] > self.stack[i+1]:
                    self.stack[i], self.stack[i+1] = self.stack[i+1], self.stack[i]
        stack_text = 'Sorted Data: ' + ','.join(map(str,self.stack))
        self.sorted_label.config(text=stack_text)

    def stack_label_update(self):
        stack_text = 'list: ' + ','.join(map(str,self.stack))
        self.sorted_label.config(text=stack_text)

    def run(self):
        self.window.mainloop()



BubbleSort_gui = BubbleSortGUI()
BubbleSort_gui.run()

    • canvas.create_rectangle(x1, y1, x2, y2, options)

      • options : outline, fill, width 등이 있음
import tkinter as tk

class Shape:
    def __init__(self, shape_name):
        self.shape_name = shape_name
    
    def draw(self):
        pass

class Circle(Shape):
    def __init__(self, shape_name):
        super().__init__(shape_name)

    def draw(self):
        canvas.create_oval(50,50,150,150,outline='red')

class Square(Shape):
    def __init__(self, shape_name):
        super().__init__(shape_name)

    def draw(self):
        canvas.create_rectangle(50,50,150,150, outline='blue')

class Triangle(Shape):
    def __init__(self, shape_name):
        super().__init__(shape_name)
    
    def draw(self):
        canvas.create_polygon(50,150,100, 50, 150, 150, outline='green', fill='white')

def draw_shape():
    shape_name = entry.get()
    canvas.delete("all")

    if shape_name.lower() == 'circle':
        shape = Circle(shape_name)
    elif shape_name.lower() == 'square':
        shape = Square(shape_name)
    elif shape_name.lower() == 'triangle':
        shape = Triangle(shape_name)
    else:
        shape = None

    if shape:
        shape.draw()
    else:
        print("Invalid shape name.")

window = tk.Tk()
window.title('Shape Drawing')

canvas = tk.Canvas(window, width=200, height=200)
canvas.pack()

label = tk.Label(window, text="Enter shape name(circle, square, triangle)")
label.pack()

entry = tk.Entry(window)
entry.pack()

button = tk.Button(window, text='Draw', command=draw_shape)
button.pack()

window.mainloop()
Example (TypingGame)

  • • entry.bind("<Return>", Lambda(람다) event: check_word()): bind() 메서드를 사용하여 입력 상자에서 <Return> (엔터) 키를 누를 때 check_word() Function(함수)를 호출, 이를 통해 입력 상자에서 엔터 키를 누를 때마다 단어 확인과 관련된 기능이 동작
import tkinter as tk
import random
import time

#단어 목록
words = [
    'apple', 'banana', 'cherry', 'date', 'elderberry', 'fig', 'grape'
]

def start_game():
    #게임 시작 함수
    global score, time_left, current_word
    if time_left == 60: # 처음 게임 시작 시 초기화
        score = 0
        time_left = 60
    entry.focus_set() # 입력 상자에 포커스 설정??
    entry.delete(0, tk.END) #입력 상자 초기화
    label_score.config(text='점수: {}'.format(score))
    label_time_left.config(text='남은 시간: {}'.format(time_left))
    label_word.config(text=current_word)
    countdown()

def check_word():
    #입력한 단어 확인 함수
    global score, current_word
    input_word = entry.get().strip().lower()
    if input_word == current_word:
        score += 1
    entry.delete(0, tk.END)
    label_score.config(text='점수: {}'.format(score))
    current_word = random.choice(words)
    label_word.config(text=current_word)

def countdown():
    global time_left
    if time_left>0:
        time_left -= 1
        label_time_left.config(text='남은 시간: {}'.format(time_left))
        window.after(1000, countdown)
    else:
        label_word.config(text='게임종료!')
        entry.delete(0, tk.END)
        entry.config(state=tk.DISABLED)

window = tk.Tk()

#점수 표시 레이블

#시작 버튼
