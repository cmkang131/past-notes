Lecture 09 · Python File I/O(파일 입출력)

강의 · Notion 아카이브
File I/O(파일 입출력) 주요 Function(함수)
open()
  • -파일을 여는 데에 이용
  • 사용 방법: open(filename, mode)
  • 모드:
    • ‘r’ ⇒ 읽기 모드: 파일을 읽기만 할 수 있다. 파일이 존재하지 않으면 오류가 발생한다.
    • ‘w’ ⇒ 쓰기 모드: 파일에 쓸 수 있다. 기존 파일이 존재하면 파일의 기존 내용이 모두 삭제되고 새로 작성된다. 파일이 존재하지 않으면 새로운 파일을 만든다.
    • ‘a’ ⇒ 추가 모드: 파일 끝에 내용을 추가한다. 기존 내용은 유지되며, 파일이 존재하지 않으면 새로운 파일을 만든다.
    • ‘b’ ⇒ 바이너리 모드: 텍스트가 아닌 바이너리 데이터를 읽고 쓸 때 사용한다. 단독으로 사용하지 않고, 'rb', 'wb'와 같이 다른 모드와 함께 사용한다.
read()
  • -파일의 내용을 읽음
  • readline():
    • 파일에서 한 줄을 읽음
  • readlines():
    • 파일의 모든 줄을 list(리스트)로 반환
write()
  • write()는 하나의 문자열을 파일에 쓴다. 줄 바꿈 문자를 자동으로 추가하지 않으므로, 줄 바꿈이 필요하면 '\n'을 문자열에 직접 포함해야 한다.
  • writelines:
    • writelines()는 문자열 리스트를 파일에 쓴다. 줄 바꿈 문자를 자동으로 추가하지 않으므로, 각 줄에 줄 바꿈이 필요하면 '\n'을 리스트의 각 문자열에 직접 포함해야 한다.
close()
  • 파일을 닫는 함수, 파일 작업 후에 꼭 사용해야 함.
with 문
  • with 문을 사용하면 파일을 자동으로 닫을 수 있음
  • with open('filename.txt', 'r') as file:
    content = file.read()
    print(content)
# with 블록이 끝나면 파일이 자동으로 닫힙니다.
파일 암호화 및 암호 해독
  • ord() → 문자의 고유 숫자를 알려줌
  • chr() → 숫자에 해당하는 문자를 알려줌
