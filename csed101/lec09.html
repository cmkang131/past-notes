Lecture 09 · Python File I/O(파일 입출력)

강의 · Notion 아카이브
File I/O(파일 입출력) 주요 Function(함수)
open()
  • -파일을 여는 데에 이용
  • 사용 방법: open(filename, mode)
  • 모드:
    • ‘r’ ⇒ 읽기 모드
    • ‘w’ ⇒ 쓰기 모드
    • ‘a’ ⇒ 추가 모드
    • ‘b’ ⇒ 바이너리 모드, 텍스트 대신 바이너리 데이터를 읽고 씀.
read()
  • -파일의 내용을 읽음
  • readline():
    • 파일에서 한 줄을 읽음
  • readlines():
    • 파일의 모든 줄을 list(리스트)로 반환
write()
  • 파일에 문자열을 씀
  • writelines:
    • 문자열 리스트를 파일에 쓰는 기능
    • 줄 바꿈 문자를 추가 X → ‘\\n’을 리스트에 넣어줘야 함
close()
  • 파일을 닫는 함수, 파일 작업 후에 꼭 사용해야 함.
with 문
  • with 문을 사용하면 파일을 자동으로 닫을 수 있음
  • ex\> with open(’filename.txt’, ‘r’) as file:
파일 암호화 및 암호 해독
  • ord() → 문자의 고유 숫자를 알려줌
  • chr() → 숫자에 해당하는 문자를 알려줌
