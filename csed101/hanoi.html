Example · Hanoi Tower(하노이 탑)

예제 · Notion 아카이브
  • > 입력 조건
    • n = 3 (원반 3개)
    • from_peg = 'A' (출발 기둥)
    • to_peg = 'C' (목적지 기둥)
    • aux_peg = 'B' (보조 기둥)
    • 실행 순서
    • 1.n-1개의 원반을 보조 기둥(aux_peg)으로 옮긴다.
    • 2.가장 큰 원반(n번 원반)을 목적지 기둥(to_peg)으로 옮긴다.
    • 3.n-1개의 원반을 보조 기둥(aux_peg)에서 목적지 기둥(to_peg)으로 옮긴다.
class hanoi_tower:
    def __init__(self, n):
        self.A = [i for i in range(n,0,-1)]
        self.B = []
        self.C = []
        self._print()
        self.move(n, self.A, self.C, self.B)
    
    def move(self, m, _from, _to, _side):
        if m == 1:

            _to.append(_from.pop())
            self._print()
            return

        # Step 1 : m-1개를 보조 기둥으로 이동
        self.move(m-1,_from,_side,_to)

        # Step 2 : 가장 큰 원반을 목적지 기둥으로 이동
        _to.append(_from.pop())
        self._print()

        # Step 3 : m-1개 보조 기둥을 목적지 기둥으로 이동
        self.move(m-1, _side, _to, _from)

    def _print(self):
        print(f'{self.A},{self.B},{self.C}')

hanoi = hanoi_tower(3)
