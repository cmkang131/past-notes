Abstract Data Type(추상 데이터 타입, ADT)
  • ‘어떤 데이터 타입은 ~ Object(객체), ~ Function(함수)로 구성되어 있다’ ⇒ 사용설명서
  • 구현 부분을 나타내지 않음 → 비공개적
  • 사용법만 알면 ⇒ 데이터 타입을 쉽게 쓸 수 있음
  • ADT를 통해 데이터나 연산이 무엇(what)인지는 알 수 있지만, 어떻게(how) 동작하는지는 알 수 없음
  • 즉, 데이터에 대한 연산들의 set(집합)을 묶어서 하나의 단위로 정의하는 프로그래밍 개념
    • ⇒ 프로그래밍 디자인과 구현을 용이하게 함
      Encapsulation(캡슐화)
      • 객체지향프로그래밍
      • 연관된 데이터와 함수를 논리적으로 묶어놓음, 데이터를 보호하기 위해 다른 객체의 접근을 제한 ⇒ Class(클래스) 명령어를 사용하여 구현할 수 있음
Object Oriented Programming (객체 지향 프로그래밍)
  • 기능을 묶어두는 것이 아니라, 데이터와 처리하는 기능을 묶은 하나의 단일 프로그램 객체
  • Abstraction(추상화)
    • 복잡한 현실 세계를 객체로 모델링 → 단순화
  • Encapsulation(캡슐화)
    • 객체의 상태와 행위를 하나로 묶어 외부에서의 접근을 제한함으로써 객체를 보호
  • Inheritance(상속)
    • 이미 있는 클래스로 새로운 클래스를 생성하는 과정

Operator Overloading(연산자 오버로딩)
  • 사용자 정의 클래스에서 +, -, *, == 같은 연산자를 직접 정의해서 사용하는 것
  • __add__를 메소드로 정의하면 + 연산자를 사용할 수 있음
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def get_vector(self):
        return self.x, self.y

v1 = Vector(1, 2)
v2 = Vector(3, 4)
v3 = v1.__add__(v2)
print(v3.get_vector())
v3 = v1 + v2
print(v3.get_vector())
  • \>(4, 6) (4, 6)
  • ⇒ v1 + v2가 자동으로 add 메서드를 호출해 (4,6)을 반환
Polymorphism(다형성)
  • inheritance 관계 내의 다른 Class들의 instance들이 같은 멤버 함수 호출(같은 방법)에 대해 각각 다르게 반응하도록 하는 기능
class Animal:
    def __init__(self, name):    
        self.name = name
    def speak(self):             
        return '알 수 없음'
 
class Dog(Animal):
    def speak(self):
        return '멍멍!'
 
class Cat(Animal):
    def speak(self):
        return '야옹!'
 
animalList = [Dog('dog1'),
             Dog('dog2'),
             Cat('cat1')]
 
for a in animalList:
    print (a.name + ': ' + a.speak())
