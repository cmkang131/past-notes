강의 · Notion 아카이브
Python list(리스트) vs Numpy Array(배열)
  • Python list
    • 장점 :
      • 유연성 - 다양한 데이터 포함, 크기가 동적
      • 내장 Function(함수) - 다양한 내장함수, Method(메서드)가 있음
    • 단점 :
      • 속도 - 반복문을 통해 요소별로 수행 ⇒ 큰 데이터에 속도 느림
      • 메모리 사용 - 요소에 대한 정보 저장을 위한 추가적인 메모리 공간 사용
  • Numpy Array
    • 장점 :
      • 성능 - C로 구현 ⇒ 반복문 없이 벡터화된 연산 수행 가능 = 빠르고 효율
      • 메모리 - 연속된 메모리 공간에 데이터를 저장, 효율적
      • 다차원 배열 지원 - 행렬연산, 다차원 데이터 처리 용이
      • 다양한 수학 함수 - 다양한 수학 함수와 연산을 제공
    • 단점 :
      • 유연성 - 한 가지 데이터 유형만 포함 ⇒ 크기의 동적 조절X
      • 추가 기능 부족 - 수학함수, 배열조작함수에 중점을 둬 추가 기능에는 제한적
Numpy 주요 함수
  • numpy.array()
    • 배열 생성. 리스트나 tuple(튜플)을 입력받아 NumPy 배열로 변환
  • numpy.zeros()
    • 모든 요소가 0인 배열을 생성, 지정된 크기의 0으로 채워진 배열 생성
  • numpy.ones()
    • 모든 요소가 1인 배열 생성.
  • numpy.arange()
    • 주어진 범위 내에서 일정한 간격으로 값이 증가하는 1차원 배열
  • numpy.linspace()
    • 주어진 범위 내에서 지정된 개수의 일정한 간격으로 값이 증가하는 1차원 배열
  • numpy.reshape()
    • 배열의 형태를 변경하는 함수. 차원과 크기를 재조정
  • numpy.transpose()
    • 배열의 차원을 변경하거나 축의 순서를 변경
  • numpy.sum()
  • numpy.mean()
  • numpy.max()
  • numpy.min()
  • numpy.matmul()
    • 다차원 배열에 대한 행렬 곱셈을 수행
  • numpy.sort()
    • 축을 지정 → 축을 따라 Sort(정렬)
  • numpy.argmax() / numpy.argmin()
  • 배열에서 최댓값/최솟값의 인덱스를 반환, 축을 지정하여 축에 따라 값을 찾음
