Lab 10 · Sort and Search(정렬과 탐색)

실습 · Notion 아카이브
Sort(정렬)
  • 자료를 선택 기준에 따라 순서대로 나열
  • Bubble Sort(버블 정렬), Selection Sort(선택 정렬), Insertion Sort(삽입 정렬)
Bubble Sort (실습 1)
  • 인접한 두 원소를 비교하여 순서에 맞지 않으면 서로 교환
def bubble_sort(nlist):
    for j in range(len(nlist)-1):
        for i in range(len(nlist)-1):
            if nlist[i] > nlist[i+1]:
                nlist[i], nlist[i+1] = nlist[i+1], nlist[i] 
        print(f'[step {j+1}] {nlist}')

L = [14, 5, 20, 13, 9, -1, -22]
bubble_sort(L)
[step 1] [5, 14, 13, 9, -1, -22, 20]
[step 2] [5, 13, 9, -1, -22, 14, 20]
[step 3] [5, 9, -1, -22, 13, 14, 20]
[step 4] [5, -1, -22, 9, 13, 14, 20]
[step 5] [-1, -22, 5, 9, 13, 14, 20]
[step 6] [-22, -1, 5, 9, 13, 14, 20]
Search(탐색)
  • 여러 개의 자료 중 원하는 자료를 찾음
  • 순차탐색, 이진탐색
Sequential Search(순차 탐색) (실습 2)
  • 정렬되지 않은 Array(배열)의 원소들을 처음부터 마지막까지 하나씩 검사하여 원
    하는 값을 찾아가는 방법
def seq_search(nlist, target):
    for i in range(len(nlist)):
        if nlist[i] == target:
            return i
    return -1

L1 = [76, 53, 80, 25, 54, 48, 79, 83, 9, 15]
target1 = 83
target2 = 200
print(seq_search(L1, target1))
print(seq_search(L1, target2))

‘*’ 사용한 언패킹
  • list(리스트), tuple(튜플) 등 반복 가능한 Object(객체)의 요소를 분해하거나, 묶는데 사용 됨
a, b, *c = [1, 2, 3, 4, 5]
print(c)
# [3,4,5]

*a, b = (10, 20, 30, 40)
print(a)
# [10,20,30]

a, *b, c = [1, 2, 3, 4, 5]
print(b)
# [2,3,4]
  • Function(함수) 호출 시 사용하면 리스트나 튜플을 개별 인자로 분해해서 전달 할 수 있음
def calc(x,y,z):
    return x+y+z

nlist = [10,20,30]
res = calc(*nlist)
print(res)
